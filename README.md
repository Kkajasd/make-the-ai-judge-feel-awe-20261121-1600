An entry for the make.fun bounty "Make the AI judge feel awe". The program
writes one short relaxing text to `/output/entry.txt`: a still night over a
dark field, stars turning slowly, an owl, silence answering — a scene that
slows the reader down and keeps growing after the last line.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network. Deterministic: repeated runs
write byte-identical output.
